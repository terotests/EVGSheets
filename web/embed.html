EVGSheets, run with parameters

One editor, one call: mountSheets(element, options). Each frame below is the same build with different options — which pieces are shown, which ribbon tools exist, and whether the workbook can be changed. The same options work as URL parameters on the editor page, e.g. ?ui=compact&theme=dark or ?ui=viewer.

EditorSource

Compact, with chosen tools

No menubar; the ribbon keeps only undo,redo,bold,italic,left,center,right,sortasc,sortdesc,chart.

mountSheets(el, { ui: "compact", tools: "undo,redo,bold,italic,left,center,right,sortasc,sortdesc,chart" })

Viewer (read-only)

Select, scroll, copy, sort and filter; nothing writes into the workbook.

mountSheets(el, { ui: "viewer" })

Bare grid, dark

Just the sheet, editable — for a host that brings its own controls.

mountSheets(el, { ui: "grid", theme: "dark" })

Inside a slide

What a presentation would embed: the viewer, sized by the slide. The buttons switch the same instance between viewing and editing without remounting it.
